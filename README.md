# Augustin-shot-prediction
I estimate the probability that an NBA shot is made from player tracking features, using 425,719 regular season shots with known outcomes. Four base models (logistic regression, a random forest, gradient boosted trees with XGBoost, and a neural network) are combined by a stacked logistic regression. Player skill enters through *makes above expected*: each shooter's and defender's average result relative to a shot difficulty model, shrunk toward zero for players with few shots, which separates skill from shot selection. Every modelling choice was made with five-fold cross-validation inside an 80% development set, and the untouched 20% holdout was scored once. The stacked model reaches a holdout log loss of 0.6207, a 10.0% reduction relative to predicting the average make rate (0.6896), and its calibration is checked on the same holdout. On the holdout it ties the best single model (XGBoost, 0.6207), which also receives by far the largest weight in the stack. Finally, I show how the predicted probabilities translate into expected points that can guide shot selection on offense and shot denial on defense.
